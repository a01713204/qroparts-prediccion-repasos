# qroparts-prediccion-repasos
El proyecto optimiza la logística de QroParts analizando 7,000 pedidos históricos mediante SQL, ingeniería de variables y modelos predictivos (Random Forest) para reducir retrasos y riesgos de inventario. Incluye un dashboard en R Shiny para facilitar la toma de decisiones y el monitoreo operativo en tiempo real.
